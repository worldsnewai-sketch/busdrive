# 동해 버스 투어

동해 시티투어 버스를 직접 운전해서 동해의 주요 관광지 세 곳을 돌아보는 3D 웹게임입니다.
빛기둥이 서 있는 정류장에 버스를 세우고 내리면 걸어 다니며 구경할 수 있고, 안내판마다 스탬프를 모을 수 있어요.

| 관광지 | 구경거리 (스탬프) |
| --- | --- |
| 묵호 도째비골·논골담길 | 논골담길 벽화 골목, 묵호등대, 도째비골 스카이워크, 해랑전망대 |
| 추암 촛대바위 | 추암해변, 해암정, 촛대바위 전망대 (해돋이 연출) |
| 무릉계곡 | 삼화사, 무릉반석(석각), 쌍폭포 |

## 동해페이 (게임 속 화폐)

| 버는 방법 | |
| --- | --- |
| 승객 태우기 | 정류장(관광지 3곳, 터미널)에 멈추면 기다리던 승객이 타고, 목적지에서 내리며 1,500원. 부딪히지 않고 모셔다 드리면 팁 500원 |
| 스탬프 | 새 스탬프마다 3,000원 |

| 쓰는 곳 | |
| --- | --- |
| 논골 바다카페 (묵호) | 아메리카노·라떼(속도 버프), 묵호항 물회, 기념품 2종 |
| 추암 해변 매점 | 아이스크림·옥수수·사이다(체력), 기념품 2종 |
| 무릉 산채식당 | 산채비빔밥·감자전·식혜, 기념품 2종 |
| 시티투어 주유소 | 연료 1%당 90원. 연료는 1km에 20%씩 줄고, 바닥나면 시속 11km로만 달림 |

걷다가 달리면 체력이 줄고, 음식과 음료로 채울 수 있어요. 기념품 6종은 여행 가방(`B`)에 모여요.

## 실행 방법

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 로컬 웹서버로 열어야 합니다.

```bash
# 둘 중 하나
npx serve .
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` (serve는 `http://localhost:3000`)을 엽니다.
Three.js는 `lib/`에 들어 있어서 인터넷 없이도 실행됩니다. 글꼴만 Google Fonts에서 받습니다.

## 조작법

**버스 운전**
- `W`/`S` 또는 `↑`/`↓`: 가속 · 브레이크(멈춘 뒤 누르면 후진)
- `A`/`D` 또는 `←`/`→`: 핸들
- `Space`: 급정거 · `H`: 경적 · `C`: 운전석 시점 / 뒤따라가는 시점
- `E`: 정류장에서 내리기
- `P`: 자동운전 — 도로를 따라 선택한 목적지 정류장까지 운전하고 도착하면 멈춥니다. 방향키를 누르면 직접 운전으로 바뀝니다.

**걸어서 구경**
- `W` `A` `S` `D`: 걷기 (`Shift`: 달리기) · `Space`: 점프
- 마우스 드래그: 시점 회전 · 휠: 확대/축소
- `E`: 안내판 읽기 · 버스 타기

**기타**: `1`~`5` 목적지 선택(묵호·추암·무릉계곡·터미널·주유소) · `B` 여행 가방 · `M` 큰 지도 · `F` 배속(1× → 2× → 4×)

휴대폰에서는 화면 왼쪽 조이스틱과 오른쪽 버튼으로 조작합니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `src/geo.js` | 수학 유틸, 노이즈, 해안선·계곡 모양 |
| `src/layout.js` | 도로, 정류장, 관광지 좌표 |
| `src/terrain.js` | 지형 높이, 도로 평탄화, 구조물 발판, 충돌 판정 |
| `src/world.js` | 하늘·시간대, 지형 메시, 바다 셰이더, 도로, 나무, 시내 |
| `src/sites.js` | 관광지 3곳 모델링과 안내판 내용 |
| `src/bus.js` | 버스 모델과 주행 물리 |
| `src/autopilot.js` | 자동운전 (도로망 최단 경로 + 경로 추종) |
| `src/economy.js` · `src/passengers.js` · `src/shops.js` | 동해페이·연료·체력, 승객, 가게와 주유소 |
| `src/player.js` | 걸어 다니는 관광객 |
| `src/hud.js` | 행선판, 미니맵, 스탬프, 안내판 UI |
| `src/input.js` · `src/audio.js` | 키보드/터치 입력, Web Audio 효과음 |
| `src/main.js` | 게임 진행 (운전 ↔ 걷기, 카메라, 정류장) |

지도와 관광지는 실제 위치 관계(묵호는 북쪽, 추암은 남쪽 해안, 무릉계곡은 남서쪽 내륙)를 단순화해서 만들었습니다.

# 모산 타자왕 (`typing/`)

모산초등학교 어린이를 위한 한글 타자연습 웹앱입니다. `typing/index.html`을 브라우저로 열면 바로 됩니다(웹서버 없이 더블클릭해도 실행).

1. 학년(1~6, 교직원)을 고르고 이름을 고릅니다. 교직원은 5~6학년 문장으로 연습합니다. 이 컴퓨터에서 그 학년으로 연습했던 이름은 버튼으로 나오고, 처음이면 이름을 씁니다.
2. 7대 안전교육 주제를 고릅니다: 생활안전, 교통안전, 폭력예방·신변보호, 약물·사이버중독 예방, 재난안전, 직업안전, 응급처치
3. 학년에 맞는 문장 5개가 무작위로 나옵니다 (1~2학년 짧은 문장, 3~4학년 중간, 5~6학년 긴 문장). 친 글자는 맞으면 초록, 틀리면 빨강으로 바로 보입니다. `Enter`로 다음 문장.
4. 5문장을 모두 입력하면 결과(점수, 1분에 친 글자 수, 정확도, 최고 기록, 걸린 시간, 별)와 함께 랭킹 화면으로 갑니다. 중간에 `그만하기`를 누르면 기록 없이 랭킹 화면으로 갑니다. **5문장을 모두 입력해야 랭킹에 등록됩니다.**
5. 첫 화면 '명예의 전당'에 전체 1위와 학년별 1위가 나옵니다. 랭킹은 전체 · 학년별 · 주제별로 볼 수 있고, 같은 이름은 가장 높은 기록 하나만 보입니다. `다시 시작하기`를 누르면 처음 화면으로 갑니다.

| 항목 | 계산 |
| --- | --- |
| 글자 수 | 1분 동안 맞게 친 글자 수 (띄어쓰기는 빼고 셈). 첫 문장은 첫 키를 누른 때부터, 다음 문장부터는 문장이 나타난 때부터 잼 |
| 정확도 | 문장 글자 수 대비 맞게 친 글자 수 (빠뜨리거나 더 쓴 글자도 실수로 셈) |
| 점수 | 1분에 친 글자 수 × 정확도 |
| 별 | 학년별 목표 점수(1학년 20 ~ 6학년 80, 교직원 100) 이상이면 3개, 60% 이상이면 2개. 정확도 70% 미만이면 1개 |

Vercel에 배포하면 `typing/api/scores.js`가 랭킹을 Vercel Blob에 저장해서, 어느 컴퓨터에서 열어도 같은 랭킹이 보입니다. 이름·학년·주제마다 최고 기록을 비공개 파일 하나(`scores/<학년>/<주제>/<이름>/<점수>_….json`)로 두기 때문에, 반 전체가 한꺼번에 기록을 올려도 서로 기다리지 않고 저장됩니다. 서버 없이 파일로 열면 그 브라우저의 `localStorage`에 저장합니다.

| Vercel 설정 | 값 |
| --- | --- |
| Root Directory | `typing` |
| Blob 스토어 | 프로젝트에 연결 (`BLOB_READ_WRITE_TOKEN` 자동 설정) |
| 환경 변수 `ADMIN_PASSWORD` | 랭킹 화면 아래 '관리자'에서 기록을 지울 때 쓰는 비밀번호 |
문장은 `typing/sentences.js`에서 주제·학년대별로 추가하거나 고칠 수 있습니다.
첫 화면의 학교 그림은 SVG로 그렸고, `typing/school.jpg` 파일을 넣으면 그 사진이 대신 보입니다.
