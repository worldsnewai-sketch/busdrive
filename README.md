# 동해 버스 투어

동해 시티투어 버스를 직접 운전해서 동해의 주요 관광지 세 곳을 돌아보는 3D 웹게임입니다.
빛기둥이 서 있는 정류장에 버스를 세우고 내리면 걸어 다니며 구경할 수 있고, 안내판마다 스탬프를 모을 수 있어요.

| 관광지 | 구경거리 (스탬프) |
| --- | --- |
| 묵호 도째비골·논골담길 | 논골담길 벽화 골목, 묵호등대, 도째비골 스카이워크, 해랑전망대 |
| 추암 촛대바위 | 추암해변, 해암정, 촛대바위 전망대 (해돋이 연출) |
| 무릉계곡 | 삼화사, 무릉반석(석각), 쌍폭포 |

## 실행 방법

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 로컬 웹서버로 열어야 합니다.

```bash
# 둘 중 하나
npx serve .
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` (serve는 `http://localhost:3000`)을 엽니다.
Three.js는 `lib/`에 들어 있어서 인터넷 없이도 실행됩니다. 글꼴만 Google Fonts에서 받습니다.

## 조작법

**버스 운전**
- `W`/`S` 또는 `↑`/`↓`: 가속 · 브레이크(멈춘 뒤 누르면 후진)
- `A`/`D` 또는 `←`/`→`: 핸들
- `Space`: 급정거 · `H`: 경적 · `C`: 운전석 시점 / 뒤따라가는 시점
- `E`: 정류장에서 내리기

**걸어서 구경**
- `W` `A` `S` `D`: 걷기 (`Shift`: 달리기) · `Space`: 점프
- 마우스 드래그: 시점 회전 · 휠: 확대/축소
- `E`: 안내판 읽기 · 버스 타기

**기타**: `1` `2` `3` 목적지 선택 · `M` 큰 지도

휴대폰에서는 화면 왼쪽 조이스틱과 오른쪽 버튼으로 조작합니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `src/geo.js` | 수학 유틸, 노이즈, 해안선·계곡 모양 |
| `src/layout.js` | 도로, 정류장, 관광지 좌표 |
| `src/terrain.js` | 지형 높이, 도로 평탄화, 구조물 발판, 충돌 판정 |
| `src/world.js` | 하늘·시간대, 지형 메시, 바다 셰이더, 도로, 나무, 시내 |
| `src/sites.js` | 관광지 3곳 모델링과 안내판 내용 |
| `src/bus.js` | 버스 모델과 주행 물리 |
| `src/player.js` | 걸어 다니는 관광객 |
| `src/hud.js` | 행선판, 미니맵, 스탬프, 안내판 UI |
| `src/input.js` · `src/audio.js` | 키보드/터치 입력, Web Audio 효과음 |
| `src/main.js` | 게임 진행 (운전 ↔ 걷기, 카메라, 정류장) |

지도와 관광지는 실제 위치 관계(묵호는 북쪽, 추암은 남쪽 해안, 무릉계곡은 남서쪽 내륙)를 단순화해서 만들었습니다.
