# 구구단 몬스터

알을 눌러 몬스터를 키우고, 2~9단 보스를 구구단으로 물리쳐 도감을 채우는 초등학생 게임입니다.
우리 반 · 우리 학교 · 우리 지역 · 전국 · 학교 대결 랭킹이 있습니다.

## 놀이 방법

- 몬스터를 누르면 먹이가 쌓이고, 먹이가 늘면 알 → 아기 → … → 우주 꼬물이로 자랍니다.
- 20번 누를 때마다 보스 도전 에너지가 하나 찹니다 (최대 3개).
- 보스 대결: 30초 안에 구구단 10문제를 맞히면 이깁니다. 하트 3개를 다 잃거나 시간이 끝나면 집니다.
- 이기면 그 단의 몬스터를 잡고, 한 번에 주는 먹이가 늘어납니다. 2~9단을 다 잡으면 섞어 단 대왕이 열립니다.
- 랭킹 점수 = 보스마다 가장 잘한 점수의 합 (한 판 최대 1,450점 = 맞힌 문제×100 + 남은 초×10 + 남은 하트×50).

## 선생님용

- 랭킹 화면의 **우리 반 친구 초대 링크**를 보내면 학교·학년·반이 미리 골라진 채로 열립니다 (`?s=학교코드&g=학년&c=반`).
- 부적절한 별명 지우기: Vercel 프로젝트에 환경 변수 `ADMIN_PASSWORD`를 정한 뒤
  `DELETE /api/scores` 에 `{ "password": "...", "id": "<랭킹 id>" }` 또는 `{ "password": "...", "school": "<학교코드>" }` 를 보냅니다.

## 구성

| 파일 | |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 게임 화면 (빌드 없음) |
| `api/scores.js` | 랭킹 API (Vercel Function + Vercel Blob, 학생 한 명당 파일 하나) |
| `schools.json` | 전국 초등학교 6,327곳 (시·도 → 시·군·구 → [학교코드, 학교명]) |

학교 목록은 학교알리미 2026년도 초등학교 기본정보에서 폐교를 뺀 것입니다
([vuski/elemstudent](https://github.com/vuski/elemstudent)의 `data/12_2026년도_학교기본정보(초).csv`를 가공).
